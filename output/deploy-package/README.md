# 员工报工系统

这是一个面向纺织工厂的员工报工和工资统计系统。

第一版目标是先完成一个可上线试用的 H5 应用：管理员维护工序、单价、员工账号和员工可报工工序；员工每日填报工序数量；系统自动计算工资；管理员和员工分别查询权限范围内的数据。

## 技术栈

- 前端：H5
- 后端：Python + FastAPI + ORM
- 数据库：PostgreSQL

## 第一版页面

1. 统一登录页面
2. 后台管理页面
3. 后台查询页面
4. 员工报工页面
5. 员工查询页面
